Публикация на Cloudflare Pages:
1. Загрузите index.html и папку assets в корень GitHub-репозитория.
2. В Cloudflare откройте Workers & Pages → Create application → Pages → Connect to Git.
3. Выберите репозиторий.
4. Framework preset: None.
5. Build command: оставить пустым.
6. Build output directory: / (корень проекта).
7. Нажмите Save and Deploy.

Кнопки скачивания ведут на последние релизы:
https://github.com/Goblin-Mini/KinozalClient/releases/latest
